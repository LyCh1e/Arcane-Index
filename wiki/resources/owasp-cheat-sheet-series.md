# OWASP Cheat Sheet Series

**URL:** https://cheatsheetseries.owasp.org/
**Index:** https://cheatsheetseries.owasp.org/Glossary.html
**Licence:** Creative Commons Attribution-ShareAlike 4.0 International
**Count:** 120 cheat sheets (as at 2026-07-09)

The OWASP Cheat Sheet Series provides concise, actionable implementation guidance for application security controls. Each cheat sheet maps to OWASP standards — Top 10, ASVS, Proactive Controls, and MASVS — making it the primary go-to reference for both implementing and verifying security controls.

**Additional indexes on the same site:**
- By ASVS: https://cheatsheetseries.owasp.org/IndexASVS.html
- By MASVS: https://cheatsheetseries.owasp.org/IndexMASVS.html
- By Proactive Controls: https://cheatsheetseries.owasp.org/IndexProactiveControls.html
- By Top 10: https://cheatsheetseries.owasp.org/IndexTopTen.html
