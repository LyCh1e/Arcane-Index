## Ecosystem Highlights

The protocol evolved from an experimental Anthropic project to the industry standard for connecting data and applications to LLMs within twelve months. Key adoption milestones:
- OpenAI integrated MCP into its Agents SDK (March 2025)
- Google DeepMind committed to MCP support (April 2025)
- Microsoft integrated MCP with Semantic Kernel and Azure OpenAI
- ChatGPT apps received MCP support for third-party access (September 2025)
