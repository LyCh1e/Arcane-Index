# INF2008 Machine Learning

**Institution:** Singapore Institute of Technology (SIT)
**Lecturer:** Donny Soh

## Module Structure

| Lecture | Topic |
|---------|-------|
| L00 | Technological trends, AI definitions, types of ML |
| L01 | Steps to train a model |
| L02 | Value generation, CRISP-DM, business understanding |
| L03 | Data understanding (EDA) |
| L04 | Baseline models, data splits, stratification |
| L05 | Decision trees (entropy, Gini, stopping criteria) |
| L06 | Model evaluation, bias-variance trade-off, cross-validation |
| L07 | Ensemble methods (Random Forests, AdaBoost, GBM) |
| L08 | Categorical encoding (label encoding, OHE) |
| L09 | Linear models I — linear regression, perceptron |
| L10 | Linear models II — gradient descent, backpropagation, activations |
| L11 | Unsupervised learning I — K-means, DBSCAN |
| L12 | Unsupervised learning II — PCA, t-SNE |
