# INF1002 Programming Fundamentals

SIT introductory programming module covering Python (Weeks 1–7) and C (Weeks 8–12). Assumes no prior programming knowledge.

---

## Structure

### Python (Weeks 1–6)

| Week | Topic |
|------|-------|
| 1 | Module intro, Python basics I — variables, types, operators |
| 2 | Python basics II — control flow (if/elif/else, while, for), I/O, f-strings |
| 3 | Advanced data structures — strings, lists, tuples, dicts; file I/O |
| 4–5 | Functions, scope, modules, recursion |
| 6 | Higher-order functions (map/filter/reduce), lambda expressions |

### C Programming (Weeks 8–12)

| Week | Topic |
|------|-------|
| 8 | C introduction — compilation, data types, printf/scanf, control flow, preprocessor |
| 9 | Functions (prototypes, call-by-value, scope), arrays, strings, string library |
| 10 | Pointers, pointer arithmetic, arrays-and-pointers, call-by-reference |
| 11 | Dynamic memory allocation (malloc/calloc/free), structs, typedef, linked lists |
| 12 | File I/O in C (fopen/fclose/fprintf/fscanf/fread/fwrite/fseek) |
