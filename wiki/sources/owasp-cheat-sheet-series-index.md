## What This Is

The OWASP Cheat Sheet Series is a curated collection of **120 security-focused cheat sheets** covering every major domain of application security — from authentication and cryptography to containerisation, AI security, and supply chain management. Each cheat sheet provides concise, actionable guidance aligned to OWASP standards (Top 10, ASVS, Proactive Controls, MASVS).

**Base URL for all cheat sheets:** `https://cheatsheetseries.owasp.org/cheatsheets/`

## Key Takeaways

- The series covers every topic referenced in ICT2216: authentication, password storage, session management, input validation, SQL injection, XSS, CSRF, cryptographic storage, logging, file upload, Docker security, CI/CD security, and dependency management
- New additions (2025–2026) reflect the AI era: MCP Security, RAG Security, AI Agent Security, LLM Prompt Injection Prevention, Secure AI Model Ops, Secure Coding with AI, AML Sanctions AI Agent Payments
