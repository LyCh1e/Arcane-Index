# INF2001 Introduction to Software Engineering

SIT introductory software engineering module covering the full SDLC from requirements to maintenance. Taught by A/Prof Frank Guan and A/P Indri Atmosukarto.

---

## Structure

| Week | Topic |
|------|-------|
| 1 | Introduction to SE & SDLC — motivation, definitions, lifecycle models |
| 2 | Requirements Engineering — elicitation, analysis, validation, management |
| 3 | Use Case Diagram and Activity Diagram |
| 4 | Class Diagram and Sequence Diagram — OOP review, noun extraction |
| 5 | Project Management — WBS, Gantt, estimation, Cone of Uncertainty |
| 8 (Part 1) | Introduction to Software Engineering Design — principles |
| 8 (Part 2) | Component Diagram — components, interfaces, ports |
| 9 (Part 1) | Software Architecture & Architectural Patterns — Layered, Client-Server, MVC |
| 9 (Part 2) | Design Patterns — GoF Creational, Structural, Behavioural |
| 10 (Part 1) | Black-Box Testing — EP, BVA, Decision Tables |
| 10 (Part 2) | White-Box Testing — CFG, Statement/Branch/Path Coverage, Cyclomatic Complexity |
| 11 (Part 1) | Software Maintenance & Refactoring — code smells, refactoring techniques |
| 11 (Part 2) | Software Configuration Management — Change Control, Version Management, CI/CD |
