# INF1003 Mathematics 1

**Singapore Institute of Technology — Academic Year 2024/25**

Discrete mathematics course covering the mathematical foundations of computer science: sequences and series, number theory, combinatorics, formal logic, proof techniques, and the theory of sets, functions, and relations.

## Topics Covered

| Topic | Key Content |
|-------|-------------|
| Sequences & Summation | AP, GP, recurrence relations, Fibonacci, summation formulas, infinite series |
| Number Theory | Divisibility, modular arithmetic, primes, GCD/LCM, Euclidean algorithm, RSA |
| Combinatorics | Product/sum rules, permutations, combinations, pigeonhole principle |
| Propositional Logic | Connectives, truth tables, tautologies, logical equivalences, De Morgan's laws |
| Predicate Logic | Predicates, universal/existential quantifiers, negation of quantifiers |
| Rules of Inference | Modus ponens/tollens, hypothetical syllogism, quantifier rules |
| Proof Methods | Direct proof, contraposition, contradiction, cases, counterexamples |
| Sets | Set operations, power sets, Cartesian products, set identities |
| Functions | Injective, surjective, bijective; composition; floor and ceiling |
| Relations | Binary relations, reflexive/symmetric/antisymmetric/transitive, equivalence relations, partial orders |
