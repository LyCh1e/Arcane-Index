## Question 1 of 30
**The timebox for a Daily Scrum is?**  
*(choose the best answer)*

- A. Two minutes per person.
- **B. 15 minutes.** ✅ *(CORRECT)*
- C. 4 hours.
- D. The same time of day every day.

## Question 20 of 30
**What are three incorrect, untrue, or misleading statements about Scrum?**  
*(choose the best three answers)*

- **A. Scrum is like traditional processes but with self-organization to replace Project Managers.** ✅ *(CORRECT — this statement is INCORRECT/misleading)*
- B. Each component of Scrum serves a specific purpose and is essential to your ability to use Scrum to develop complex products.
- C. Scrum is a framework for developing and sustaining complex products.
- **D. Scrum is a framework that eliminates complexity.** ✅ *(CORRECT — this statement is INCORRECT/misleading)*

## Key Scrum Facts Summary

| Topic | Key Fact |
|-------|----------|
| Scrum Team size | Typically 10 or fewer people |
| Scrum Team roles | Product Owner, Scrum Master, Developers |
| Daily Scrum timebox | 15 minutes (regardless of Sprint length) |
| Sprint Planning timebox | Max 8 hours for a 1-month Sprint |
| Sprint Review timebox | Timeboxed (max 4 hours for 1-month Sprint) |
| Sprint Retrospective | Timeboxed |
| Daily Scrum attendees | The Developers (required) |
| Three pillars of Scrum | Transparency, Inspection, Adaptation |
| Sprint cancellation authority | Only the Product Owner |
| Reason to cancel Sprint | Sprint Goal becomes obsolete |
| Product Backlog ordering | PO decides what is most appropriate |
| Number of Product Backlogs | One per product (regardless of # of teams) |
| Sprint start | Immediately after previous Sprint ends |
| Increment release requirement | Must be usable; does NOT have to be released |
| Scrum has "project manager" role | FALSE — no such role exists in Scrum |
| Scrum is a... | Lightweight framework (not methodology/process) |
| Who manages Sprint progress | The Developers |
| Developer replacement | As needed; account for short-term productivity loss |
| Definition of Done (multi-team) | All teams must share a single DoD |
| Who creates Definition of Done | Scrum Team (if not an org standard) |
| Timebox definition | Maximum duration; cannot exceed |
| Developer work per Sprint | Enough for Increment to meet Definition of Done |
| Product Owner responsibility | Maximize value of the Scrum Team's work |
| Management's role in Scrum | Support PO and SM; no official team role |
