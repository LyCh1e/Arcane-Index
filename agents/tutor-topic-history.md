# Tutor Agent — Topic Rotation History

Tracks roughly the last 5 runs' subtopics per module, so the tutor agent can avoid repeating recent content without needing to scan local daily files (there are none any more — see `agents/tutor-artifact-links.md`). Each run appends its selections to the relevant module's list and prunes older entries down to about 5.
